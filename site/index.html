COVID-19 tracker, 2020⁠–⁠2021

This page is an archive. It tracked COVID-19 from March 2020 to January 2021 with data from the European Centre for Disease Prevention and Control (ECDC) and is no longer updated; the table's counts run to mid-January 2021. In October 2026 the charts of 63 countries in the table, which had gone missing, were redrawn from the last ECDC file kept, which ends on 10 January 2021, and images that no longer loaded were removed.
